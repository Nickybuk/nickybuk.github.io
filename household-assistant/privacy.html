Privacy policy

Household Assistant is a private tool used by one household. Last updated 8 November 2026.

Google data it uses

  • Gmail: messages in its own mailbox, to pick out dates and events, label them and reply.
  • Google Calendar: a calendar it created, and calendars shared with it.

It uses this data only to provide those features to the household that runs it.

What it never does

  • Sell data, share it outside the household, or use it for advertising.
  • Use Google data to train AI models.

Storage

Data is kept privately by the household. Working data is deleted automatically after a short period; anything else is kept only until the household deletes it.

Google API Services User Data Policy

Household Assistant's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be removed at any time at myaccount.google.com/permissions.

Contact

Use the support email address shown on the Google sign-in screen for this app.
